1. Project Overview

Yu Zhong is a long-running xianxia worldbuilding and narrative project supported by a structured Master Story Bible, character registries, cultivation systems, timeline records, and story-state checkpoints.

This repository preserves exported documentation and structured records to support continuity, world simulation, and future development.

2. Core Principles

* Preserve established canon and explicit creator decisions.
* Never invent confirmed canon from unverified drafts, rumors, or proposals.
* Maintain traceable story history and checkpoint references.
* Preserve existing records before making structural changes.
* Verify changes before declaring synchronization complete.

3. Timeline Isolation

MAIN-001 — Main Timeline

Contains the primary storyline, its confirmed events, character relationships, inventory, and active story state.

SBX-001 — Sandbox Timeline

Isolation Rule: Events, characters' knowledge, relationships, inventory, cultivation changes, and consequences must not transfer between MAIN-001 and SBX-001 without explicit creator authorization.

5. Canon Authority

When resolving conflicting records, apply the established canon hierarchy:

1. Explicit creator decisions and instructions.
2. Permanent system rules and established constitution.
3. Confirmed canon that has not been superseded.
4. The verified active checkpoint for the relevant timeline.
5. Supporting ledgers and historical records.
6. Drafts, hypotheses, rumors, and proposals.

Do not resolve unresolved canon conflicts by guessing.

7. Data Integrity

* Do not permanently delete historical records without explicit authorization.
* Do not overwrite source files without a verified backup.
* Check duplicate-looking CSV exports before removing any.
* Keep timeline-specific Save States separate.
* Record significant changes and verify the resulting content.
* Do not claim that an automated backup or synchronization has run unless verified.
